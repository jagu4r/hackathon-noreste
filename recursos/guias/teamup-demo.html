Consejo

Nunca proceses 200 llamadas a la IA en paralelo: revientas el rate limit del proveedor. Usa un tope de concurrencia (aquí, 5) y reintentos con espera creciente. Si una falla, márcala y sigue — degradación elegante.

código: cola con concurrencia limitada (mapLimit) 
async function mapLimit(items, limit, fn) {
  const results = []; let cursor = 0;
  async function worker() {
    while (cursor < items.length) {
      const i = cursor++;
      results[i] = await withRetry(() => fn(items[i]));  // reintenta si falla
    }
  }
  // lanza "limit" trabajadores que se reparten la cola
  await Promise.all(Array.from({ length: limit }, worker));
  return results;
}

Consejo

Pide a la IA un formato estructurado (JSON con esquema) y valídalo antes de usarlo. Y dile explícitamente: "no inventes datos; si un campo no aparece, usa null". Así reduces alucinaciones.

código: extracción con caché por hash 
const SYSTEM = `Eres un parser de CVs. Extrae { nombre, anios_experiencia,
  skills[], educacion }. No inventes: si falta, usa null.`;

async function extractPerfil(cvRaw) {
  const key = hash(cvRaw);
  if (cache.has(key)) return cache.get(key);  // gratis
  const perfil = await withRetry(() =>
    llm.json({ system: SYSTEM, input: { cv_raw: cvRaw } }));
  cache.set(key, perfil);
  return perfil;
}

Consejo

La normalización ligera (sinónimos, minúsculas, quitar ".js") resuélvela con un diccionario en código — barato y exacto. Reserva la IA solo para skills nuevos o ambiguos que el diccionario no conoce. No todo necesita un LLM.

código: normalización con diccionario + fallback a IA 
const ALIAS = { 'reactjs':'react', 'react.js':'react',
  'nodejs':'node', 'js':'javascript', 'ts':'typescript' };

function normalizar(skill) {
  const s = skill.toLowerCase().trim();
  return ALIAS[s] ?? s;            // barato y exacto
}
// Si normalizar() no lo conoce, ahí sí preguntas a la IA.

Evalúa a todos los candidatos de una vacante con IA usando map-reduce: cada uno se puntúa por separado y el ranking se arma en código. Aguanta cientos sin reventar el contexto.

Cómo funciona

Map-reduce: el patrón que salvó a TeamUp

1
N candidatosCada uno con su perfil compacto.
2
MAPCada uno se puntúa solo, en paralelo (limitado).
3
REDUCEOrdenas y filtras en código: exacto y gratis.
4
RankingLos mejores arriba, con su motivo.

Vacante: Desarrollador Frontend Senior

requiere: react, typescript

Consejo

Haz que la IA haga lo único que solo ella puede (entender el CV) y deja ordenar/filtrar/contar al código. Es exacto, instantáneo y gratis. Mezclar ambos bien es lo que distingue un proyecto sólido.

código: map-reduce sobre los candidatos 
// MAP: cada candidato por separado, 5 en paralelo, con reintentos
const scored = await mapLimit(candidatos, 5, (c) =>
  withRetry(() => llm.json({
    system: 'Devuelve {score:0-100, motivo}.',
    input: { vacante, candidato: c.perfil }   // JSON chico
  })));
// REDUCE: ordenar es trabajo de CÓDIGO, no del LLM
const ranking = scored.sort((a, b) => b.score - a.score);
