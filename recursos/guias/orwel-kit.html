Qué es Orwel

Una herramienta que escucha tu producto

En palabras simples

Imagina que tu página web es una tienda. Orwel es como un ayudante invisible que anota cuánta gente entra, qué miran, en qué botón hacen clic y quién deja sus datos para comprar. Tú no tienes que estar mirando: Orwel lo apunta todo y te lo muestra ordenado.

Para quien construye: Orwel es un SDK de analítica de front-end (paquete npm orwel) más una API. Identifica visitantes, detecta eventos automáticamente, encola y reenvía sin perder datos, y suma inteligencia de leads con IA en el panel.

Visitantes

Sabe quién llega, de dónde viene y si ya había estado antes, sin pedir login.

Eventos

Clics, vistas de página, scroll y formularios. Manuales o detectados solos.

Conversiones

Cuando alguien deja su correo o pide una demo, queda registrado como lead.

Inteligencia

El panel resume y califica cada lead con IA, y enriquece datos de la empresa.

Personalidades

Deduce rasgos de cada visitante por su comportamiento. Úsalos para personalizar, segmentar o priorizar.

El SDK manda datos a Orwel; Orwel los procesa y los muestra; tú puedes leerlos de vuelta con la API REST para construir lo tuyo.

Inicio rápido

De cero a midiendo en cinco minutos

¿Aún no tienes tu llave?

Vuelve al Paso 0 y créala en orwel.io (gratis, un minuto). La necesitas para que el SDK envíe datos.

  1. Instala el paquete

    Si tu proyecto usa Node (React, Next, Vue, Svelte, Astro…):

    Terminal
    npm install orwel

    ¿Solo tienes un HTML simple, sin Node? Usa el CDN antes de cerrar </body>:

    index.html
    <script src="https://cdn.orwel.io/orwel.js"></script>
<script>
  orwel.init({ apiKey: 'orwel_tu_llave_aqui' });
  orwel.track('page_view', { path: location.pathname });
</script>

  2. Guarda tu llave de forma segura

    Nunca escribas la llave directamente en el código que subes a GitHub. Ponla en un archivo .env (y agrega .env a tu .gitignore). El nombre de la variable cambia según el framework:

    FrameworkVariable en tu .env
    SvelteKit / AstroPUBLIC_ORWEL_KEY=orwel_xxx
    Next.jsNEXT_PUBLIC_ORWEL_KEY=orwel_xxx
    Vite (React / Vue)VITE_ORWEL_KEY=orwel_xxx
    Create React AppREACT_APP_ORWEL_KEY=orwel_xxx
    Nuxt 3NUXT_PUBLIC_ORWEL_KEY=orwel_xxx

  3. Inicializa una sola vez

    Crea un módulo que lea la llave y arranque Orwel. Ejemplo para React + Vite:

    src/lib/orwel.ts
    import { orwel } from 'orwel';

export function initOrwel() {
  const apiKey = import.meta.env.VITE_ORWEL_KEY;
  if (!apiKey) {
    console.warn('Falta VITE_ORWEL_KEY — Orwel no se inicializará.');
    return;
  }
  orwel.init({ apiKey, autoMonitor: true });
}

export { orwel };

    Llama initOrwel() una vez al arrancar la app (en main.tsx o en el layout raíz). Debe correr en el navegador, no en el servidor.

Cómo usarlo

Los siete comandos que necesitas

Importa el mismo orwel en cualquier parte de tu app y llama estos métodos. Nunca vuelvas a hacer init.

track — registrar un evento

cualquier componente
orwel.track('button_click', { button_id: 'comprar' });

El nombre del evento va en snake_case: minúsculas, números y guion bajo, máximo 50 caracteres.

identify — decir quién es el visitante

al conocer al usuario
orwel.identify({ email: 'ana@empresa.com', plan: 'pro' });

conversion — capturar un lead

en tu handler de envío
// Desde v1.6 conversion es asíncrono: usa await
await orwel.conversion('demo_request', {
  email: 'ana@empresa.com',
  source: 'landing_page'
});

Importante

El correo es obligatorio para leads. Si la conversión no trae email (aquí o vía un identify previo), el panel la registra pero no envía la notificación.

Los otros cuatro

MétodoPara qué sirve
orwel.session(props, final?)Guardar estado de la sesión (página activa, valor del carrito). Pasa true para marcar el fin.
orwel.monitor(opts?)Instrumentación pasiva: rendimiento, errores, consola y red. Sin argumentos, activa todo.
orwel.form(el, opts)Observa un formulario (foco, escritura, envío, abandono). No lo combines con un conversion manual en el mismo form.
await orwel.flush()Fuerza el envío de la cola. Rara vez necesario: se envía solo al cerrar la página.

Medir secciones sin escribir JavaScript

Agrega data-orwel-section="hero" a cualquier elemento. Orwel mide solo cuánto se vio, qué porcentaje alcanzó y los clics dentro.

HTML
<section data-orwel-section="hero-principal"> ... </section>

Para builders avanzados

API REST: construye sobre tus datos

Idea

El SDK manda datos. La API te deja leerlos: puedes construir tu propio dashboard, un bot, o conectar Orwel con otra herramienta. Aquí es donde un proyecto de hackathon se vuelve interesante.

Base: https://api.orwel.io · Autenticación: header Authorization: Bearer <tu_api_key>

Traer tus últimos leads
const res = await fetch('https://api.orwel.io/api/v1/leads?limit=20', {
  headers: { Authorization: `Bearer ${API_KEY}` }
});
const { data, pagination } = await res.json();
EndpointQué devuelve
GET /api/v1/leadsLista de leads, con resumen y score de IA. También POST para crear.
GET /api/v1/identitiesVisitantes identificados. /:id/activity da su recorrido; /:id/personalities sus rasgos.
GET /api/v1/companiesEmpresas enriquecidas detrás de tus leads.

Personalidades

Orwel infiere rasgos de cada visitante a partir de cómo se comporta. Pídelos en GET /api/v1/identities/:id/personalities y úsalos para adaptar el mensaje, mostrar distinto contenido o priorizar a quién contactar primero. Ideal para un proyecto que se sienta inteligente.

Seguridad

La API_KEY de servidor es secreta. Las llamadas de lectura a la API hazlas desde tu backend, no desde el navegador.

Si algo falla

  • ¿El conversion no llega? Asegúrate de hacer await antes de cambiar la pantalla que oculta el formulario.
  • ¿La consola dice “key is not defined”? Tu variable de entorno no se está leyendo — revisa el nombre exacto del framework.
  • ¿Nada aparece en el panel? Confirma que init corre en el navegador y que la llave empieza con orwel_.
  • Para instalación asistida, usa la skill de Orwel en tu asistente de IA (Claude Code, Gemini CLI, Cursor…), incluida en el pack de Hyper Skills.
