# Hackathon Noreste — Solución para la región Noreste de México

> Reto: **desarrollar una solución que resuelva una problemática de la región Noreste de México.** La propuesta más creativa gana.

Este repositorio parte del kit del **Hackathon Hyperdigital × Google** (sábado 27 de junio de 2026) y lo usamos como base para construir nuestra solución.

## Qué hay aquí

| Carpeta / archivo | Qué es |
|---|---|
| `src/`, `supabase/`, `index.html`, `package.json`… | **Template TeamUp MVP** (React + Vite + TypeScript) — la base de código sobre la que construimos. Corre con datos mock sin configurar nada. |
| `docs/TEMPLATE.md` | Arquitectura y estructura del template MVP. |
| `COMO_PROBAR.md` | Paso a paso para correr el MVP localmente (para principiantes). |
| `recursos/` | Material del hackathon: guías, catálogo de *skills*, demos y assets. Ver [`recursos/README.md`](recursos/README.md). |

## Correr el MVP

```bash
npm install
npm run dev        # http://localhost:5173 — corre con datos mock
```

Para conectar Supabase y/o IA real, copia `.env.example` a `.env` y llena los valores. **Nunca subas el `.env` real** (ya está en `.gitignore`).

## El reto

- **Problema a resolver:** una problemática de la región Noreste de México (Nuevo León, Coahuila, Tamaulipas).
- **Criterio principal:** creatividad de la solución.
- **Estado:** definiendo el problema y la propuesta. *(Completar a medida que avancemos: problema elegido, propuesta de valor, demo y entrega.)*

## Recursos

Las guías están en `recursos/guias/` (HTML autocontenidos) y el pack de *skills* de IA en `recursos/skills/`. El detalle de cada recurso está en [`recursos/README.md`](recursos/README.md).
